# Requirements and capability matrix

Status vocabulary: **implemented-simulated** = real logic, automated tests, but only against the synthetic SAP adapter ·
**catalogued** = data/catalog only, no execution engine · **planned** = not started · **designed** = documented only.
**Nothing in this repository is production-ready against a real SAP system.** (Generated from `backend/rfactory/capabilities.py`.)

## Deployment-model support

| Capability | ECC 6.0 on-prem | S/4HANA on-prem | S/4HANA Private Cloud (RISE PCE) |
|---|---|---|---|
| Discovery, dependency graph, selective copy (simulated adapter) | ✅ simulated | ✅ simulated (Business Partner, ACDOCA) | ⚠ same model; real access limited to released APIs/contractual scope |
| ABAP extraction agent | ❌ not built | ❌ not built | ❌ not built; clean-core / released-API constraints apply |
| Full system copy | catalogued | catalogued | ⚠ SAP-run in PCE; orchestration limited to request/approval and validation |
| ECC ↔ S/4HANA | out of scope: conversion/migration, blocked by the pair guard | | |
| M18 Benchmarks and calibrated estimates | Duration estimates fitted from measured samples per phase (extract, mask+stage, load, reconcile) and per environment: least squares seconds = a + b*rows with one robust outlier pass, an 80% prediction interval (wider when extrapolating), a leave-one-out error and a quality grade; refuses to fit with fewer than 5 samples, 3 sizes or a 2x span; samples recorded automatically from plan builds and clean runs only, from a benchmark harness (growing scopes masked and loaded into a scratch target) and from declared imports; environments never mix ('simulated', 'platform', remote profiles, operator-bound real labels; reserved labels cannot be imported); plausibility cap on imports; predicted-vs-actual accuracy and interval coverage tracked per run; estimates fall back to a labelled placeholder until every phase is calibrated; performance agent reports calibration state; Benchmarks view | implemented-simulated | Platform timing model (simulator, masking engine, remote read) | Simulator and masking timings measure this Python program on this host, NOT SAP: a calibrated estimate for simulated systems says nothing about a real refresh; imported measurements are declared by the importer and cannot be verified; linear in rows only (no row width, index, parallelism or contention terms); phases assumed independent when combining intervals; no real-system benchmark has been run | tests/test_benchmark.py, tests/test_agents.py, frontend/e2e/benchmarks.spec.ts | Run controlled measurements on real ECC and S/4 sandboxes (extract, load, reconcile) and import them under real:<label>; add multivariate terms; scheduled re-calibration |
